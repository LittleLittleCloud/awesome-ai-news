# Contributing Guidelines

Thank you for your interest in contributing to Awesome AI News & RSS Aggregation!

## How to Contribute

### Adding a New Project

1. **Fork** this repository
2. **Create** a new branch (`git checkout -b add-new-project`)
3. **Add** your project to the appropriate category in `README.md`
4. **Follow** the format:
   ```markdown
   - **[Project Name](link)** ⭐⭐⭐ - Brief description (1-2 sentences). *Optional tag*
   ```
5. **Commit** your changes (`git commit -am 'Add ProjectName'`)
6. **Push** to the branch (`git push origin add-new-project`)
7. **Create** a Pull Request

### Project Requirements

To be included, a project should:

- ✅ Be related to AI-powered news aggregation, RSS management, or content automation
- ✅ Have a clear README with installation instructions
- ✅ Be actively maintained (updated within the last 6 months) OR be a stable, production-ready project
- ✅ Have a valid open-source license
- ✅ Work as described in its documentation

### Quality Standards

- **Description**: Clear, concise, and accurate (1-2 sentences)
- **Category**: Place in the most appropriate category
- **Rating**: Use ⭐ (1-5 stars) based on:
  - Functionality completeness
  - Documentation quality
  - Active maintenance
  - Community adoption
- **Tags**: Optional tags like *Most Active*, *Production Ready*, *Best Architecture*

### Categories

If you think a new category is needed:

1. Open an issue first to discuss
2. Provide at least 3 projects for the new category
3. Explain why existing categories don't fit

### Updating Existing Projects

- Update descriptions if they're outdated
- Update links if they've changed
- Update ratings if project status has significantly changed
- Add a note in the PR explaining the changes

### Removing Projects

Projects may be removed if they:

- Are no longer maintained (>2 years without updates)
- Have broken links
- No longer meet quality standards
- Have been deprecated by authors

## Code of Conduct

- Be respectful and constructive
- Focus on the project, not the person
- Welcome newcomers and help them contribute
- Follow GitHub's [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)

## Questions?

Open an issue with the `question` label.

# 贡献指南

感谢你对 Awesome AI News & RSS Aggregation 的贡献兴趣！

## 如何贡献

### 添加新项目

1. **Fork** 本仓库
2. **创建** 新分支 (`git checkout -b add-new-project`)
3. **添加** 你的项目到 `README.md` 的适当分类中
4. **遵循** 格式:
   ```markdown
   - **[项目名称](链接)** ⭐⭐⭐ - 简短描述（1-2句话）。*可选标签*
   ```
5. **提交** 更改 (`git commit -am 'Add ProjectName'`)
6. **推送** 到分支 (`git push origin add-new-project`)
7. **创建** Pull Request

### 项目要求

要被收录，项目应该:

- ✅ 与 AI 驱动的新闻聚合、RSS 管理或内容自动化相关
- ✅ 有清晰的 README 和安装说明
- ✅ 积极维护（最近 6 个月内有更新）或是稳定的生产就绪项目
- ✅ 有有效的开源许可证
- ✅ 功能与文档描述一致

### 质量标准

- **描述**: 清晰、简洁、准确（1-2句话）
- **分类**: 放在最合适的分类中
- **评分**: 使用 ⭐（1-5星）基于:
  - 功能完整度
  - 文档质量
  - 活跃维护
  - 社区采用度
- **标签**: 可选标签如 *最活跃*、*生产就绪*、*最佳架构*

### 分类

如果你认为需要新分类:

1. 先开 issue 讨论
2. 提供至少 3 个项目用于新分类
3. 解释为什么现有分类不合适

### 更新现有项目

- 如果描述过时，更新描述
- 如果链接变更，更新链接
- 如果项目状态显著变化，更新评分
- 在 PR 中说明更改原因

### 移除项目

以下情况项目可能被移除:

- 不再维护（>2年无更新）
- 链接失效
- 不再符合质量标准
- 作者已弃用

## 行为准则

- 尊重和建设性
- 关注项目，而非个人
- 欢迎新人并帮助他们贡献
- 遵循 GitHub 的[社区指南](https://docs.github.com/zh/site-policy/github-terms/github-community-guidelines)

## 有问题？

开一个带 `question` 标签的 issue。
